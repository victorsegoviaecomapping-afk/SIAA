# Procedencia científica

La implementación deriva de la especificación del PDF maestro incluido en `reference/` y de las fuentes suministradas durante el diseño (CEFR, English Grammar Profile, Nation, Lightbown & Spada, Vandergrift & Goh, BKT, Knowledge Spaces, HLR, POMDP, etc.).

Los libros/PDFs de terceros no se redistribuyen dentro de este ZIP. Este repositorio contiene únicamente implementación propia, esquemas y contenido de demostración.
