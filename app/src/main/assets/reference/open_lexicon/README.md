# Open lexicon overlay used by SIAA

`contexto_cefr_overlay.json` is a derived, conservative lexical overlay created by intersecting:

1. CEFR-J / Open Language Profiles vocabulary levels, and
2. English→Spanish entries from the public MIT-licensed `Jason-Latz/contexto` Spanish language pack.

Only entries selected during the SIAA authoring pass are bundled. This file is not a copy of either full upstream dataset.

Upstream references:
- https://github.com/openlanguageprofiles/olp-en-cefrj
- https://github.com/Jason-Latz/contexto

The active content pack additionally contains human/model-authored original teaching prompts, distractors, examples and chunks. Those should not be interpreted as upstream dataset content.
