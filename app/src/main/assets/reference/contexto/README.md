# Contexto Spanish language pack — selected CEFR-aligned entries

`contexto_cefr_v16_selected.json` is a selected subset of English→Spanish entries from the Contexto Spanish language pack, cross-referenced against the bundled CEFR-J/Open Language Profiles vocabulary profiles before activation in SIAA.

Source project: `Jason-Latz/contexto`, file `public/language-packs/es.json`.

## Licensing note

Contexto source code is MIT licensed. However, Contexto's own `THIRD_PARTY_NOTICES.md` states that the distributed Spanish pack incorporates FreeDict-derived data and that affected language-pack data is distributed under **CC BY-SA 3.0**. SIAA therefore does not describe the selected language-pack subset as purely MIT data; it preserves attribution and treats the derived lexical subset conservatively under the applicable share-alike obligations.

The CEFR level does **not** come from Contexto. It is assigned/validated against CEFR-J/Open Language Profiles.

SIAA uses only reviewed/filtered entries and keeps the upstream source separate from original SIAA authoring.
