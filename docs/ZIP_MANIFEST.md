# Manifiesto del ZIP v2.3

- `app/`: aplicación Android, currículo Pre-A1–C2, MediaSession y banco offline de audio.
- `core/model/`: tipos puros.
- `core/algorithm/`: learner model, memoria y adaptación.
- `core/runtime/`: tutor ejecutable independiente de Android.
- `core/data/`: persistencia Room y migraciones.
- `core/audio/`: TTS, foco, guard de salida y earcons.
- `docs/`: arquitectura, build, QA, protocolos físicos/lingüísticos/audio y roadmap.
- `scripts/`: gates de contenido/audio/lingüística, importación de audio humano, smokes, ADB y bootstrap Gradle.
- `tools/`: programas Kotlin de smoke/regresión.
- `reference/`: PDF maestro y checksum.
- `research_sources/`: trazabilidad/política de procedencia sin redistribuir fuentes no incluidas.
- `.github/workflows/`: validación rápida, build Android y tests instrumentados en emulador.
- `FILES_SHA256.txt`: manifiesto reproducible de integridad del release.
