## Regla de calidad

No se considera un nivel “terminado” sólo por alcanzar un número de palabras. Cada entrada debe tener un sentido objetivo defendible, glosa española, evidencia CEFR, audio y tareas de recuperación/transferencia. B2→C2 siguen siendo la siguiente prioridad.
