# Fuentes y autoría — v2.1

La segunda capa formulaica se escribió específicamente para SIAA. No copia ejercicios ni ejemplos de libros comerciales.

Se usa como marco de nivelación y selección funcional:

- CEFR Companion Volume 2020;
- CEFR-J / Open Language Profiles;
- British Council / EAQUALS Core Inventory ya referenciado en el proyecto;
- Nation para el tratamiento de unidades multiword y conocimiento léxico;
- referencias de pragmática y gramática ya incorporadas al registro de fuentes de SIAA.

Los ejemplos en inglés y las glosas españolas de las nuevas unidades son authoring original de SIAA. El audio se genera offline con eSpeak y continúa marcado explícitamente como sintético.
