# Procedencia del contenido — v1.5

Las pasadas v1.3–v1.5 usan CEFR-J/Open Language Profiles únicamente para validar el nivel del headword. Las glosas españolas añadidas, los prompts y las instrucciones de transferencia son contenido original SIAA.

Los libros/PDFs proporcionados y fuentes abiertas se usan como referencias de diseño (qué conocimiento entrenar, cómo secuenciarlo y qué tipos de tareas emplear), no como bancos copiados.
