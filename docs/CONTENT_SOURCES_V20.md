# Fuentes y política de contenido — v2.0

## 1. CEFR Companion Volume

Se utiliza como referencia de resultados comunicativos, listening, competencia pragmática y progresión fonológica A1–C2. La v2.0 usa especialmente la progresión de control de sonidos, stress, rhythm e intonation para diseñar objetivos perceptivos.

## 2. CEFR-J / Open Language Profiles

- `cefrj-vocabulary-profile-1.5.csv`: nivelación A1–B2.
- `octanove-vocabulary-profile-c1c2-1.0.csv`: extensión C1/C2, CC BY-SA 4.0.
- `cefrj-grammar-profile-20180315.csv`: granularidad gramatical.

El nivel CEFR de los lexemas importados no se toma de la traducción española; se contrasta con estos perfiles.

## 3. Contexto Spanish language pack

Se usa un subconjunto revisado para glosas inglés→español. Contexto source code es MIT, pero su aviso de terceros indica que el Spanish pack incorpora FreeDict y que los datos afectados están bajo CC BY-SA 3.0. SIAA conserva attribution/provenance y no etiqueta el pack completo como MIT.

## 4. Nation — Learning Vocabulary in Another Language

Guía la decisión de modelar conocimiento léxico como algo multidimensional: forma, significado, uso, recuperación, spelling y unidades multiword. El libro se usa como referencia metodológica; no se redistribuye su texto.

## 5. Vandergrift & Goh — Teaching and Learning Second Language Listening

La v2.0 incorpora explícitamente planificación, monitoreo y evaluación/reescucha. Los guiones y preguntas son originales SIAA; la fuente se utiliza para el diseño de la secuencia pedagógica.

## 6. Celce-Murcia et al. — Teaching Pronunciation

Referencia metodológica para contraste segmental, stress, rhythm, intonation y connected speech. Los estímulos de SIAA son authoring propio y audio sintético pre-renderizado.

## 7. British Council / EAQUALS Core Inventory

Se usa como referencia de progresión de funciones, discurso y contenido por nivel. No se copia un banco de ejercicios del documento.

## 8. Authoring original SIAA v2.0

La expansión v2.0 añade 197 nuevas unidades formulaicas sobre la base previa, ejemplos contextuales originales, listening original y pragmática original. Las expresiones comunes se seleccionan por utilidad comunicativa y se nivelan en coherencia con el conjunto CEFR-J/Core Inventory del proyecto.
